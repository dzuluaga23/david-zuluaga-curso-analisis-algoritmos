\# Laboratorio 02 — Configuración del entorno de trabajo



El entorno virtual del proyecto se creó en la raíz del repositorio con `py -m venv venv`.

Se activó en Windows con `venv\\Scripts\\activate`.

La terminal muestra `(venv)` para confirmar que el entorno está activo.

Dentro del entorno se instaló `matplotlib` con `pip install matplotlib`.

Las dependencias se registraron con `pip freeze > requirements.txt`.

Para reproducir el entorno, se debe crear nuevamente el `venv` y activarlo.

Luego se instalan las dependencias con `pip install -r requirements.txt`.

Los scripts del laboratorio se encuentran en `ejercicios-clase/semana-02/`.

# Curso de Análisis de Algoritmos

Repositorio utilizado para almacenar el material desarrollado durante el curso de Análisis de Algoritmos.

## Estructura del repositorio

- **laboratorios/**: contiene los informes y desarrollos correspondientes a los laboratorios evaluativos del curso.
- **ejercicios-clase/**: almacena ejercicios, ejemplos y prácticas realizadas durante las sesiones de clase.
- **benchmarks/**: incluye scripts y herramientas utilizadas para medir tiempos de ejecución y analizar el rendimiento de algoritmos.
- **README.md**: documento principal del repositorio, donde se describe su propósito, organización y forma de uso.
- **.gitignore**: define los archivos y directorios que Git debe ignorar para evitar versionar archivos temporales o configuraciones locales.

## Uso del repositorio

Para obtener una copia local del repositorio, ejecute el siguiente comando:

```bash
git clone <https://github.com/dzuluaga23/curso-analisis-algoritmos.git>
```

Una vez clonado, puede acceder al directorio del proyecto con:

```bash
cd curso-analisis-algoritmos
```

Los cambios realizados pueden registrarse en el historial del proyecto mediante Git:

```bash
git add .
git commit -m "Describe el cambio realizado"
git push origin main
```
